# Как опубликовать свой сайт в интернете через GitLab Pages

> Эта инструкция для человека, который никогда не видел Git и терминал.
> Всё делаем через сайт GitLab.com в браузере. Никакого терминала. Бесплатно.

В конце у тебя будет ссылка вида `https://твой-логин.gitlab.io/summer-school/` — открывается с любого устройства, где есть интернет.

---

## ⏱ Сколько времени займёт

Первый раз — около 30 минут. Дальше обновлять сайт — 2 минуты.

---

## 🟢 ШАГ 0. Что должно быть на компьютере

Папка `summer-school` со всеми файлами:
```
summer-school/
├── index.html
├── styles.css
├── app.js
├── data.js
├── README.md
├── GITLAB-INSTRUCTIONS.md
└── SUMMER-PROGRAM.md
```

Проверь: открой `index.html` двойным кликом — сайт должен открыться в браузере. Работает? Идём дальше.

---

## 🟢 ШАГ 1. Создать аккаунт на GitLab

1. Открой в браузере: **https://gitlab.com**
2. В правом верхнем углу нажми кнопку **«Register»** (или «Sign up», что значит «Зарегистрироваться»).
3. Заполни форму:
   - **First name** — твоё имя (Маша)
   - **Last name** — фамилия
   - **Username** — твой логин (только латинские буквы и цифры). **Запомни его** — он будет в ссылке на твой сайт. Например: `masha-sails`.
   - **Email** — почта (например, мамина, если своей нет)
   - **Password** — пароль (запомни или запиши!)
4. Нажми кнопку **«Register»**.
5. GitLab пришлёт письмо на почту. Открой почту, найди письмо от GitLab, нажми кнопку **«Confirm your email»** внутри письма.
6. Готово — у тебя есть аккаунт.

---

## 🟢 ШАГ 2. Создать новый проект (репозиторий)

1. Войди на gitlab.com (если выйшел) — нажми «Sign in» в правом верхнем углу.
2. На главной странице слева вверху найди фиолетовую кнопку **«Create new...»** (плюсик «+») или зайди по адресу: **https://gitlab.com/projects/new**
3. Откроется страница «Create new project». Выбери **«Create blank project»** (создать пустой проект) — это первая большая карточка.
4. Заполни поля:
   - **Project name:** напиши `summer-school`
   - **Project slug** — заполнится автоматически, оставь как есть (`summer-school`)
   - **Project deployment target (optional)** — пропусти, ничего не выбирай
   - **Visibility Level** — выбери **«Public»** (Публичный). Это важно, иначе сайт не откроется в интернете без логина.
   - **Initialize repository with a README** — поставь галочку ✅ (это создаст «начинку» проекта).
5. Нажми синюю кнопку внизу **«Create project»**.

Через 2 секунды откроется страница твоего нового проекта. Адрес будет вида:
`https://gitlab.com/твой-логин/summer-school`

---

## 🟢 ШАГ 3. Загрузить файлы сайта в GitLab

1. На странице проекта найди кнопку **«+»** (плюс) — она в шапке проекта рядом с названием.
2. В выпадающем меню выбери **«Upload file»** (загрузить файл).
3. Откроется окно. Нажми **«click to upload»** или перетащи файлы.
4. **ВАЖНО:** GitLab не позволяет загрузить много файлов за раз через эту кнопку. Поэтому будем загружать **по одному**.

### Загружаем `index.html`:

1. Нажми «click to upload», выбери файл `index.html` из папки `summer-school` на компьютере.
2. Внизу окна есть поле **«Commit message»**. Туда напиши: `Добавить index.html`
3. Нажми синюю кнопку **«Upload file»**.
4. Подожди 2–3 секунды — файл появится в списке проекта.

### Загружаем остальные файлы — повторяй то же самое:

Снова **+** → Upload file → выбираешь файл → пишешь «Добавить ...» → жмёшь Upload.

Сделай это для:
- `styles.css`
- `app.js`
- `data.js`
- `SUMMER-PROGRAM.md`

(README.md уже создан автоматически при создании проекта — его трогать не надо. Если хочешь обновить — нажми на него, потом кнопку «Edit» сверху.)

После загрузки в списке файлов проекта должно быть как минимум:
```
README.md
app.js
data.js
index.html
styles.css
SUMMER-PROGRAM.md
```

## 🟢 ШАГ 4. Включить GitLab Pages (магия публикации)

Чтобы файлы стали сайтом в интернете, нужен один специальный файл — `.gitlab-ci.yml`. Он говорит GitLab: «опубликуй эти файлы как сайт».

### Создаём .gitlab-ci.yml через интерфейс:

1. На странице проекта нажми кнопку **«+»** в шапке.
2. Выбери **«New file»** (новый файл).
3. В верхнем поле **«File name»** напиши ровно так:
   ```
   .gitlab-ci.yml
   ```
   (точка вначале, дефис, без пробелов)

4. В большое поле снизу (туда, где будет содержимое файла) вставь **точно этот текст**:

```yaml
pages:
  stage: deploy
  script:
    - mkdir public
    - cp -r * public/ || true
  artifacts:
    paths:
      - public
  rules:
    - if: $CI_COMMIT_BRANCH == $CI_DEFAULT_BRANCH
```

5. Внизу страницы найди поле **«Commit message»** — напиши `Включить GitLab Pages`.
6. Нажми зелёную кнопку **«Commit changes»** внизу.

### Что произойдёт после этого:

1. GitLab запустит «работу» (job) по сборке сайта. Это автоматически.
2. Через 1–3 минуты сайт будет опубликован.
3. Чтобы проверить — слева в меню найди раздел **«Build»** → **«Pipelines»**. Там увидишь «pipeline» (трубопровод) с галочкой ✅ когда готово.

---

## 🟢 ШАГ 5. Найти ссылку на свой сайт

1. В левом меню найди раздел **«Deploy»** → **«Pages»**.
2. Откроется страница «Pages». Там будет надпись типа:
   > Your pages are served under: **https://твой-логин.gitlab.io/summer-school**
3. **Это твоя ссылка!** Кликни — откроется сайт. Можешь скопировать в адресную строку любого устройства.

⚠️ **Первый раз ссылка может не работать** 5–10 минут — GitLab «прогревает» сайт. Если выдало 404 — подожди немного и обнови страницу.

---

## 🟢 ШАГ 6. Сохрани ссылку

- Добавь ссылку в закладки браузера на телефоне и компьютере.
- Можешь поделиться с мамой, чтобы она тоже могла открыть.

## 🔄 Как обновить сайт потом

Допустим, ты редактировала `data.js` (добавила задачи). Чтобы новая версия появилась в интернете:

1. Зайди на gitlab.com → найди свой проект `summer-school`.
2. Кликни на нужный файл (например, `data.js`) в списке.
3. Справа сверху нажми кнопку **«Edit»** → **«Edit single file»**.
4. Внизу нажми **«Replace»** (заменить) и загрузи новую версию файла.
   *(Или редактируй прямо в браузере и нажми «Commit changes».)*
5. GitLab сам пересоберёт сайт. Через 1–2 минуты обновится по той же ссылке.

## ❗ Частые проблемы и их решение

**Проблема:** Открыла ссылку — пишет «404 Not Found»
- **Решение 1:** Подожди 5–10 минут после первой публикации.
- **Решение 2:** Проверь, что pipeline в Build → Pipelines зелёный (готов). Если красный — кликни на него и посмотри, что не так. Чаще всего — опечатка в `.gitlab-ci.yml`.
- **Решение 3:** Проверь, что в проекте есть файл `index.html` именно с маленькой буквы.

**Проблема:** Сайт открывается, но без стилей (всё текстом)
- Проверь, что файлы `styles.css`, `app.js`, `data.js` действительно загружены — открой проект, посмотри список файлов.

**Проблема:** Не могу залогиниться
- Сбрось пароль: на странице входа кнопка «Forgot your password?»

**Проблема:** Хочу удалить проект
- Settings (внизу левого меню) → General → Advanced → раздел «Delete project». Только осторожно — назад не вернёшь.
