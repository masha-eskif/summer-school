# Лето с Машей — учебный сайт

Сайт-планировщик для подготовки к ОГЭ + теория парусного спорта. 12 недель, 5 дней в неделю, 60 минут в день.

## Что внутри

```
summer-school/
├── index.html              ← открой этот файл в браузере
├── styles.css              ← дизайн
├── app.js                  ← логика (расписание, проверка ДЗ, графики)
├── data.js                 ← вся программа: 60 дней + парус + бонусы
├── README.md               ← этот файл
├── GITLAB-INSTRUCTIONS.md  ← как опубликовать сайт в интернет
└── SUMMER-PROGRAM.md       ← текстовая версия программы (для печати)
```

## Быстрый старт (на своём компьютере)

1. Открой папку `summer-school`.
2. Дважды кликни на `index.html` — откроется в твоём браузере.
3. Всё работает локально, без интернета (видео-ссылки требуют интернет).

## Что умеет сайт

- **📚 Сегодня** — какую тему учить сегодня, видео по теме, повторение старого, ДЗ с автоматической проверкой и оценкой 2–5. После хорошего ДЗ (≥70%) — случайный бонус (анекдот / цитата / медалька).
- **⛵ Парус** — все 4 раздела теории (ветер, аэродинамика, узлы, правила гонок), мини-тесты, связь с физикой.
- **📓 Дневник** — таблица всех твоих занятий.
- **📈 Прогресс** — графики оценок по дням и средние по неделям.
- **⚙️ Настройки** — число задач в ДЗ, дата старта, экспорт/импорт JSON, сброс.

## Как редактировать программу

Открой `data.js` в любом текстовом редакторе (Блокнот, VS Code).

**Добавить задачу:**
```js
{ q: 'Текст вопроса', type: 'number', answer: 42, tolerance: 0.1, units: 'м' }
{ q: 'Текст', type: 'text', accept: ['ответ1', 'ответ2'] }
{ q: 'Текст', type: 'choice', options: ['A','B','C'], correct: 1 }
```

**Добавить парусный урок** — найди нужную категорию в `SAILING.categories` и допиши элемент в массив `lessons`.

**Добавить анекдот/цитату** — допиши строку в массив `BONUSES.jokes` / `quotes` / `medals`.

## Где хранится мой прогресс?

В браузере, в localStorage. Это значит:
- Прогресс не пропадёт, даже если закроешь страницу.
- НО: если очистишь историю браузера — пропадёт.
- НО: если откроешь в другом браузере — прогресса там не будет.

**Совет:** раз в неделю экспортируй JSON-резервную копию (вкладка «Настройки» → «Экспорт в JSON»).

## Хочу заниматься с любого устройства

См. файл `GITLAB-INSTRUCTIONS.md` — там пошагово, как бесплатно опубликовать сайт в интернет (получишь ссылку вида `https://твой-логин.gitlab.io/summer-school/`). Тогда сможешь открывать с телефона, планшета, компьютера.

⚠️ Учти: даже опубликованный, прогресс всё равно хранится в каждом браузере отдельно. Используй экспорт/импорт JSON для переноса.
